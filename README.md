 Contact Book Application

  Project Description:
   A simple Python-based Contact Book application that allows users to manage their contacts through a command-line interface.

  Features:
   - Add new contacts
   - View all saved contacts
   - Search contacts
   - Store contact details in a text file
   - Exit the application

  Technologies Used:
   - Python
   - File Handling
   - Functions
   - Exception Handling
  How to Run:
   1. Download or clone this repository.
   2. Open the project folder in VS Code.
   3. Run the following command:

   python contact_book.py
